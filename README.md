# FadeBridge support

FadeBridge is a macOS audio application from Amperative for managing music between performances.

- [Product information and screenshots](https://amperative.co/fadebridge)
- [Setup and troubleshooting](https://amperative.co/fadebridge/support)
- [Report a bug](https://github.com/Amperative/fadebridge-support/issues/new/choose)

This repository contains public support resources, not the application source code.

## Before reporting a bug

Include your FadeBridge version, macOS version, primary and secondary apps, audio output device, steps to reproduce, and what you expected to happen. Tell us whether the issue occurs during normal playback, a transition, or a device change.

Reports are public. Do not include passwords, account details, personal information, licensed media, or unredacted logs. For private questions, email [sami.elhini@amperative.co](mailto:sami.elhini@amperative.co?subject=FadeBridge%20support).
